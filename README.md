# RPG Telegram Bot — Камария

Текстовый RPG-бот для Telegram: подземелья, бои, крафт, алхимия, кланы, PvP-арена,
торговая площадь и сюжетный режим. Плюс отдельная Streamlit-панель администратора.

## Структура

```
bot/
  main.py            точка входа, middleware, фоновый воркер
  database.py        слой БД (SQLite), схемы, миграции, игровые расчёты
  handlers/          хендлеры aiogram по игровым зонам
  data/              статические игровые данные (предметы, мобы, локации, лут)
  locales/           каталоги переводов ru.json / en.json
  i18n.py            t(), t_plural(), contextvar текущего языка
  utils/             генераторы подземелий, эффекты зелий, титулы
  config.example.py  шаблон конфига
admin_panel/
  main.py            Streamlit-панель (правка контента и игроков)
scripts/
  check_locales.py   проверка паритета ключей и плейсхолдеров
requirements.txt
```

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Создайте конфиг:

   ```bash
   cp bot/config.example.py bot/config.py
   ```

   и заполните `BOT_TOKEN`, `DB_PATH`, `ADMIN_ID`.

3. Запустите бота из папки `bot` (там же создастся/прочитается `game_data.db`):

   ```bash
   cd bot
   python main.py
   ```

4. Панель администратора:

   ```bash
   streamlit run admin_panel/main.py
   ```

   Пароль задаётся переменной окружения `ADMIN_PASSWORD` или полем
   `ADMIN_PASSWORD` в `bot/config.py`. Путь к БД можно переопределить
   переменной `RPG_DB_PATH`.

## Переменные окружения

| Переменная       | Назначение                                   |
|------------------|----------------------------------------------|
| `ADMIN_PASSWORD` | пароль Streamlit-панели                      |
| `RPG_DB_PATH`    | путь к SQLite-базе для панели                |
| `ADMIN_ID` / `ADMIN_IDS` | Telegram ID админов (через запятую)  |

## Локализация

- Язык игрока хранится в `users.language` (`ru` по умолчанию), переключается
  командой `/language`. Существующие аккаунты не переключаются автоматически
  по локали Telegram.
- Тексты интерфейса — плоские ключи в `bot/locales/*.json`; в коде используется
  `t("town.btn.inventory")`. Для числительных есть `t_plural()`.
- Текущий язык на время update задаёт `LanguageMiddleware` в `bot/main.py`,
  поэтому фоновые уведомления и ответы берут язык из `users.language`.
- Игровые данные не содержат русского текста в качестве ключей:
  свойства алхимии — ID (`heal`, `fire_damage`), кастомные зелья —
  `potion_custom:armor+heal`, титулы — `title_id` (`war_hero`), медали —
  `war_defender_<region_id>`.
- Проверка каталогов:

  ```bash
  python scripts/check_locales.py
  ```

  Скрипт падает при расхождении ключей, плейсхолдеров или дубликатах.

> Существующую базу удалять не нужно: в ней хранятся сюжет и прогресс игроков.
> Перед обновлением сохраните резервную копию. Старые идентификаторы следует
> проверять и при необходимости мигрировать на копии базы.

Для точечного исправления известных ошибок в сюжетных данных можно сначала
посмотреть изменения, затем применить их к заранее сохранённой копии базы:

```bash
python scripts/migrate_story_fixes.py /path/to/game_data.db
python scripts/migrate_story_fixes.py /path/to/game_data.db --apply
```

Миграция повторно применима; она меняет только известные старые значения.

## Медали

Медали хранятся в `home_data.medals` как стабильные ID и не зависят от языка.
Активную медаль игрок выбирает в доме.

- Война за Камарию — отдельная медаль за каждый регион:
  `war_participant_<region_id>` (1 зачистка), `war_defender_<region_id>` (10),
  `war_veteran_<region_id>` (50), `war_hero_<region_id>` (100) и
  `war_liberator_<region_id>` (финальная зачистка региона).
- Если регион зачищают несколько игроков одновременно, медаль
  «Освободитель» получает каждый участник финальной волны. Регионы
  сбрасываются после освобождения всех регионов; задержка задаётся
  настройкой `war_reset_delay_seconds` (по умолчанию 3600 секунд).
- Стартовая цель региона — 1000 зачисток (`WAR_REGIONS` в
  `bot/data/locations.py`). Для уже созданной базы цель меняется в
  админ-панели (таблица `war_regions`) или SQL-запросом; `seed_all()`
  не перезаписывает существующие регионы.
- PvP — медали по грейду боя (`pvp_easy_*`, `pvp_even_*`, `pvp_hard_*`,
  `pvp_legend_*`) и по общему числу побед.
- Также есть медали за уровни, серию ежедневных визитов, сюжеты,
  убийства/боссов, крафт, алхимию, мини-игры, загадки и коллекцию карт.

Пороги и ID описаны в `bot/utils/titles.py` (`STAT_MEDALS`,
`LEVEL_MEDALS`, `STREAK_MEDALS`, `CARD_MEDALS`, `WAR_MEDAL_THRESHOLDS`).

## Заметки по эксплуатации

- БД — SQLite. Бот и панель могут работать одновременно, но панель не стоит
  использовать для массовых правок во время активной игры.
- При первом запуске создаются таблицы и наполняются статические данные
  (`seed_all`); существующие записи контента и настройки при рестарте
  сохраняются, таблица добычи заполняется только если она пуста.
- `bot/config.py` в репозиторий не коммитится.
